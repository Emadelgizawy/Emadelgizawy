# 🏠 منصة مطابخ الجيزاوي

منصة ويب شاملة لعرض وتخصيص المطابخ الحديثة مع خدمات المراسلة والحجوزات

## المميزات الرئيسية
- 🛍️ تصفح المنتجات (أجهزة، مقاسات، تصاميم)
- 🎨 محرر تفاعلي لتخصيص المطبخ
- 📐 معاينة ثلاثية الأبعاد
- 📞 تواصل عبر WhatsApp و Facebook Messenger
- 📅 حجز معاينة ورفع المقاسات
- ⚙️ لوحة إدارة متقدمة
- 🌍 واجهة عربية كاملة

## التقنيات المستخدمة
- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **3D Viewer**: Three.js
- **Admin Panel**: React Admin

## الملفات الرئيسية
```
kitchens-platform/
├── client/                 # تطبيق الويب الأمامي

├── database/               # نماذج قاعدة البيانات

```
